# 抖音

## 一句话
国内最大的短视频平台。OPC 在它上面既是作者（个人品牌线主发平台），又是读者（采集系统把它当信源）。智能体常拿它干：读博主视频的文案和口播、看创作者后台数据、查电商和小程序规则。

## 智能体怎么进门
- 读公开内容：网页版靠脚本渲染加签名（a_bogus），直接抓常被风控挡；采集系统走第三方付费接口 TikHub 解析视频、取无水印音频再 ASR。
- 开放平台：抖音开放平台的内容与数据接口受限、要资质；个人主体现行文档支持创建抖音小程序，功能受限（OPC 内部记录，2026-10-25）。
- 创作者中心：只有网页后台，要登录；OPC 用 Claude in Chrome 扩展在主人保持登录态的浏览器里只读看数据。
- 写操作（发布、评论、私信）：没有给个人的发布 API；OPC 规定发布永远人手点，全自动发布封存。

## 我们的经验
- 2026-07 起个人品牌线以抖音为主发平台，矩阵含小红书、视频号（OPC 内部记录，2026-07）。规矩：发布／互动永远本人手点，全自动发布封存（平台风控）。
- 采集系统抖音采集：yt-dlp 的抖音 extractor 长期反复失效，是死路；f2 无 cookie 从 NAS IP 调抖音 API 被风控挡（`APIRetryExhausted`）；最终走 TikHub 付费接口，与账号解耦。2026-06 抖音转写全链闭环：TikHub 解析→无水印音频→ASR→摘要→入库（OPC 内部记录，2026-06）。
- 账号纪律：专用抓取运营号"保号高于抓数"，任何用其登录态的抓取必须低频、只读、不对抗风控（OPC 内部记录，2026-10-25）。
- 创作者中心数据基线：用浏览器扩展只读读取，扩展本身不存密钥（OPC 内部记录，2026-10-25）。
- 规则（2026-10-17 核验）：抖音电商引导站外交易不行，罚金加码、店铺清退；中视频伙伴计划已下线，创作者伙伴计划有粉丝门槛。合规路径排序：粉丝群＞主页简介＞直播口播；口播提"GitHub/Gitee"低风险，放链接二维码高风险（OPC 内部记录，2026-10-25）。
- 2026-08-25：抖音外贸博主拆解 9 条逐字稿作对标研究（OPC 内部记录，2026-08-25）。

## 已知阻力
- 进得去：机器人指纹和签名风控强，开源下载器反复失效，机房 IP 被挡；正文和评论要登录。
- 看得懂：内容是视频，正文锁在口播里，要 ASR；文案简介可取；网页壳靠脚本渲染。
- 办得成：没有给个人的发布接口；抖音小程序个人主体可建但功能受限，短视频挂载要评级、信用分、且禁"收集线索"。
- 稳不稳：接口和反爬改得快，工具链要靠付费第三方扛。
- 能付钱：个人只做获客，分成计划门槛够不到。
- 守规矩：条款禁自动化访问；《诱导第三方》新规 AI 检测 700 多种引流话术变体。
