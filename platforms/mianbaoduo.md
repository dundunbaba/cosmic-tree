# 面包多

## 一句话
面向创作者的作品售卖与收款工具，个人可开，带支付回调（面包多 Pay），是国内少数个人能拿到"下单→回调"接口的通道。OPC 把它列为自动收款备胎，没有真开过。

## 智能体怎么进门
- 面包多 Pay：个人实名开通，下单接口加支付回调，可做站内自动发卡。
- 作品页：公开可读；上架要登录。

## 我们的经验
- 2026-07 第一桶金方案：费率 2% 加 0.1 元，支付宝约 5 分钟到账，最便宜最快，但平台脆弱（审核收紧、曾迁域名），定为"1 元生成一次"自动收款备胎（OPC 内部记录，2026-07）。
- 收款通道速查：带支付回调，站内真自动发卡（中期）（OPC 内部记录，2026-10-25）。
- 2026-10-16：偏创作者打赏，不适合软件订阅，抽成比例没查到具体数（OPC 内部记录，2026-10-16）。
- 插件变现方案里"国内仍走面包多"（OPC 内部记录，2026-10-25）。

## 已知阻力
- 进得去：网页为主，要登录。
- 看得懂：没核过 API 文档完整度。
- 办得成：个人能开回调，是优点。
- 稳不稳：平台存续风险被我们列为已知薄弱点。
- 能付钱：买方付款走支付宝／微信；代收费率 2% 加 0.1 元。
- 守规矩：条款没核。
