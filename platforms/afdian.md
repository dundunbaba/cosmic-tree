# 爱发电

## 一句话
创作者赞助与会员平台，个人身份证实名即可开，买家免注册，走官方微信／支付宝清算，提供查询赞助者的 API。OPC 2026-06 把它定为无执照阶段的收款载体，后来没有开通。

## 智能体怎么进门
- 开放 API：`query-sponsor` 等接口，`token + params + ts + user_id` 做 md5 签名，返回赞助者的 `current_plan` 和 `expire_time`，可在自己服务端做站外会员校验。
- 创作者页公开可读；建会员档位要登录。
- 兑换码自动发送：官方文档缺失，上架前要实测。

## 我们的经验
- 2026-06-16 收款方案：阶段 0 用爱发电做收款载体，费率约 6%，`query-sponsor` 做站外会员校验，半天上线、合规风险最低（OPC 内部记录，2026-06-16）。
- 回款慢：次月 1 日加 3 个工作日，7 月收款 8 月到手；只作公众号场景合规出口（OPC 内部记录，2026-10-25）。
- "兑换码自动发送"配置细节官方文档缺失，列入待核实清单（OPC 内部记录，2026-10-25）。
- 买家免注册加微信／支付宝双通道经审计员二次核实 confirmed（OPC 内部记录，2026-10-25）。
- 没有开通、没有收到过钱。

## 已知阻力
- 进得去：页面公开；开通要实名。
- 看得懂：API 文档有；自动发码文档缺。
- 办得成：有查询 API，无下单回调（和面包多的差别）。
- 稳不稳：没测过。
- 能付钱：买家免注册是优点；回款月结。
- 守规矩：持牌平台代收，是我们认定的安全出口之一。
