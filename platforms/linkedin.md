# LinkedIn

## 一句话
职场社交网络，OPC 外贸业务找欧洲中型制造厂决策人的主阵地。国际版 2021-11 起不再服务大陆，国内只剩"领英职场"（只有招聘，没有内容和互动）。2026-08-31 主人亲手建了号，规矩是前两周一个好友申请都不发。

## 智能体怎么进门
- 读：公司主页、个人页要登录；没有可用的公开内容 API（官方 API 偏企业营销，个人拿不到）。
- 写：免费号每月只有 5 条带附言的好友邀请；发帖、评论、私信人工做；官方明列的封号触发：新号猛加人、申请没人通过、用自动化插件。
- 网络：要代理，且登录 IP 要稳——节点频繁跨国跳是最典型的异常信号。

## 我们的经验
- 2026-08-25 前置条件：国内看到的是领英职场不是国际版；用国际邮箱注册；固定一个节点一直用（OPC 内部记录，2026-08-25）。
- 2026-08-31 建号实况：中文界面强制汉字真名，切 English 才能填拼音；Company 下拉里的都是别人建的主页一条别选；两个同名公司页可能是两家公司，按地址核不按关注数；关注前后看关注数加一来验证关注对了谁；约 1 小时（OPC 内部记录，2026-08-31）。
- 28 条获客门路里 27 条不花配额、13 条不需要领英账号；"先去官网、新闻页、招聘页挖人名"比在领英上拐弯强（OPC 内部记录，2026-10-25）。
- 领英只做人工验证，不批量爬（违规会封号）（OPC 内部记录，2026-10-25）。
- 主人问"这些操作你不能替我做吗"——写作、筛选可以，发布和加人是人闸（OPC 内部记录，2026-10-25）。

## 已知阻力
- 进得去：大陆不可达；登录墙；IP 稳定性风控。
- 看得懂：页面脚本渲染；字段名和文档对不上（Description 叫 Highlights）。
- 办得成：没有个人可用的 API；配额每月 5 条附言。
- 稳不稳：风控严，新号容易被限。
- 能付钱：Premium／Sales Navigator 付费；个人免费档够起步。
- 守规矩：条款禁自动化和插件；GDPR 对冷联系有约束。
