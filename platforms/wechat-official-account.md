# 微信公众号

## 一句话
微信里的图文发布平台，国内最大的长文内容池之一。智能体常拿它干两件事：读别人的公众号文章当信源；替主人经营自己的号（发文、看流量主）。

## 智能体怎么进门
- 读公开文章：文章永久链接 `mp.weixin.qq.com/s/...` 浏览器能直接打开，不要登录；但没有官方 RSS、没有公开的文章列表接口，列表要进自己的公众号后台搜。
- 开放接口：公众平台开放 API 只对自己的公众号（素材、群发、用户管理），要用公众号的 AppID 和密钥；个人订阅号只有一部分接口。
- 第三方：we-mp-rss（登自己公众号后台）、wewe-rss / Wechat2RSS（登微信读书小号）、新榜／极致了／TikHub 等付费数据接口。
- 没有 MCP、CLI；没有给智能体的机器人账号。

## 我们的经验
- 2026-06-13：采集系统的公众号公开文章直抓器验收通过，本机跑、往链接文件里喂 URL 即可（OPC 内部记录，2026-06-13）。
- 2026-06-06：we-mp-rss 本机 Docker 跑通，但卡在扫码——它要登录微信公众平台后台，而公众号数量按身份证算、一个身份证只能有 1 个个人公众号，当时账号到了上限要先注销一个（约 7 天）（OPC 内部记录，2026-06-06）。
- 2026-06-22：选型改为"微信读书小号"路线（wewe-rss）更优——不用公众号、风险不压主资产；we-mp-rss 降为备选（OPC 内部记录，同上）。
- 2026-06：从 Vercel（海外 IP）抓公众号正文被「环境异常」拦；手机在国内 IP 上能抓到标题，所以标题对账改在手机端做（OPC 内部记录，2026-06）。
- 2026-10：调研时直取一篇公众号原文撞到"环境异常／去验证"的验证码，jina 代理也被拦（OPC 内部记录，2026-10）。
- 红线：采集系统信源采集"公众号不买号不借号"；公众号开流量主要 500 粉；"套壳 ChatGPT 收费"的公众号被处罚案例（OPC 内部记录，2026-10-25）。

## 已知阻力
- 进得去：海外 IP 抓正文被拦；直取常撞验证码；文章列表要登录公众号后台；账号数量按身份证限 1 个。
- 看得懂：文章页是 HTML，正文能提取；但没有 RSS、没有机器可读的列表接口，第三方转 RSS 工具时好时坏。
- 办得成：写操作（发文）只能对自己的号，个人订阅号权限少；没有给智能体的正规写入通道。
- 稳不稳：第三方 RSS 工具依赖登录态，过期要人扫码；wewe-rss 已归档不再维护。
- 能付钱：不涉及智能体付钱；收入侧只有流量主、赞赏，门槛见上。
- 守规矩：条款没有写明自动化；平台层对"诱导""外链未备案域名"有限制（OPC 内部记录，2026-10-25）。
