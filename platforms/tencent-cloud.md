# 腾讯云

## 一句话
OPC 用它干三件事：EdgeOne Pages／Makers 托管网页版产品（全球区默认子域名，零备案）、个人 ICP 备案（域名加国内云资源）、微信小程序的云开发后端。对智能体最友好的一块是 EdgeOne 命令行：一条命令部署、返回 JSON。

## 智能体怎么进门
- EdgeOne Pages／Makers：命令行 `edgeone`（npm 装），`login --site china` 登国内站，`deploy --json` 返回固定网址、项目 ID、部署 ID；登录凭据存在用户目录，不进项目。全球可用区（不含中国大陆）默认子域名不用备案；要中国大陆加速得实名加备案域名。
- Makers 内置模型 `@makers/jev`，不用自己申请 key，只支持 `/v1/systemone`（不支持 chat 协议、不支持流式），模型网关还有混元、智谱、DeepSeek 等，key 放环境变量；云函数有月配额。
- 备案：腾讯云 App 控制台"ICP 备案"，个人主体，人脸核验；备案资源三选一（轻量应用服务器包 3 个月以上／云函数资源包／云开发），EdgeOne 不在备案资源名单里。
- 云开发：小程序侧云函数、云存储；"小程序算法备案"通道要企业认证小程序。

## 我们的经验
- 2026-10-17 验载体：建测试项目，直接上传型，加速区 overseas；一句话静态页加只回 ok 的云函数三次全通，首页 1.2～3.2 秒、函数 0.37～1.3 秒；但 CEO 手机流量实测我们的默认子域名回 401（平台规矩：默认网址有访问限制），官方演示域名能开约 2 秒（OPC 内部记录，2026-10-17）。
- 2026-10-17：读文档确认 Jev 是 Makers 内置模型、走 `/v1/systemone`、共用每月免费 Token 配额（OPC 内部记录，2026-10-17）。
- 2026-10-17 备案单：备案本身免费，花钱只有域名和云资源；备案期间域名不能在国内打开；建议选轻量应用服务器；备案通过后机器要一直留着，释放了会被取消接入（OPC 内部记录，2026-10-17）。
- 2026-10-18 核（腾讯云备案助手口径）：个人备案的网站不许登录、评论、收费、广告、经营性内容——所以备案域名只给纯展示主页，产品放 EdgeOne 全球区（OPC 内部记录，2026-10-18）。
- 2026-10-18 CEO 定域名，在腾讯云（DNSPod）等实名审核 1～3 个工作日（OPC 内部记录，2026-10-18）。
- 游戏项目小程序阶段用过云开发云函数（OPC 内部记录，2026-10-25）。
- 新用户轻量服务器有低价首单，老用户看活动页（OPC 内部记录，2026-10-25）。

## 已知阻力
- 进得去：控制台和备案要人实名、人脸；命令行部署对智能体顺。
- 看得懂：文档公开；备案资源要求、个人备案禁区分散在文档和备案助手两处。
- 办得成：默认子域名国内手机流量 401（待查清是哪条平台规矩）；中国大陆加速要备案。
- 稳不稳：Makers 是新产品，模型协议只支持一种，文档要边做边读。
- 能付钱：免费额度加按量；购买要人付。
- 守规矩：个人备案网站五不许；EdgeOne 不能当备案资源。
