# 火山引擎

## 一句话
字节跳动的云与大模型平台（豆包模型走火山方舟）。OPC 接触它的方式比较特别：作为"方舟众测平台"的出题人，给被测大模型出题、提交、收结果、写评价；模型 API 本身只在调研里出现过。

## 智能体怎么进门
- 众测平台：只有网页（Arco 组件库的下拉和表单），要主人登录；新建任务要先传附件（单次不超过 10MB）再填标题、Prompt、Rubrics；运行结果走 GitHub 分支拉取。令牌只由主人贴，智能体不读不存。
- 模型 API（火山方舟）：OpenAI 兼容接口，要开账号拿 key；豆包输入法没有直接 API，底层引擎在火山引擎（OPC 内部记录，2026-10-25）。
- 平台红线：自动化刷单、完全依赖 AI 检验产物并生成评价＝0 元并取消资格。

## 我们的经验
- 2026-09 起参加方舟众测，建了专门工作区和助理技能：每一步停下等主人确认、不自动推进；结果只走 GitHub 不看平台 Workspace；梯度交付最多三阶段（主人 2026-09-27 定）（OPC 内部记录，2026-09）。
- 浏览器提交的坑：下拉框要对 `.arco-select-view` 依次发 mousedown/mouseup/click；提交按钮变灰卡住绝不重复点，事后查任务数防重复；先确认页面 `visibilityState` 可见（OPC 内部记录，同上）。
- 2026-09-27：一期众测产出被收割进外贸业务作参考资料（OPC 内部记录，2026-09-27）。
- 模型 API 没接过；模型管理中心的供应商表里"二十家厂商"由 uni-api 翻译，火山是否已配未在内部记录里写明。

## 已知阻力
- 进得去：众测后台纯网页、要登录；通知走飞书。
- 看得懂：表单是脚本渲染的组件，没有接口；任务说明在下拉框里。
- 办得成：能替主人填表，但提交点击是人闸；令牌不能经智能体手。
- 稳不稳：按钮状态机有卡住风险。
- 能付钱：众测是平台付我们，评价质量不过关 0 元。
- 守规矩：禁刷单、禁 AI 代评。
