# TikTok

## 一句话
抖音的海外版，对大陆用户按 IP 加 SIM 国别双重屏蔽。OPC 为跨境货源业务查清了：从大陆做是灰色高危，从海外做是正路。没有开过账号。

## 智能体怎么进门
- 开发者平台有登录、内容发布、研究 API，要申请；读公开内容靠第三方（TikHub 含 TikTok 接口）。
- 风控对"账号出身与行为不一致"极敏感：设备指纹、IP／ASN、SIM、行为突变→限流、反复验证、封号。
- Creator Rewards Program 开放国不含中国；要求人实际位于开放国加账号注册于该国；VPN 伪装＝违反条款、永久封号加没收收益。日本门槛：18 岁、个人账号、1 万粉、近 30 天 10 万播放。
- TikTok Shop 跨境 2025 起不收个人与个体户，要大陆或香港企业执照（成立满 60 天）。

## 我们的经验
- 2026-07 调研 F1～F7：国内应用商店不上架、国际服被阻断；大陆个人翻墙有行政处罚个案（200～1000 元）；2026-01 美区业务交割给合资公司，美区对中国背景账号的政策是要季度复核的环境变量（OPC 内部记录，2026-07）。
- 结论：内容与 IP 走日本身位全正规，账号全生命周期绑日本环境，回深拍摄期不裸网操作账号（OPC 内部记录，2026-10-25）。
- 2025-04 关税潮中中国工厂探访类内容在 TikTok 爆红，赛道流量已验证（同上 F11）。
- 没有账号、没有调过 API。

## 已知阻力
- 进得去：大陆双重屏蔽；账号风控强。
- 看得懂：视频为主，字幕不如 YouTube。
- 办得成：发布 API 要申请；电商不收个人。
- 稳不稳：政策随地缘变。
- 能付钱：创作者奖励按国家开放。
- 守规矩：条款禁自动化、禁位置伪装。
