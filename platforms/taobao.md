# 淘宝

## 一句话
国内最大的综合电商。OPC 只把它列为获客渠道候选（个人店身份证可开），没有真开过；外贸业务的合作方在淘宝有店，作情报用。

## 智能体怎么进门
- 读商品页：网页脚本渲染加登录墙，直接抓困难；淘宝开放平台 API 面向商家和服务商，要入驻审核。
- 开店：身份证开个人店；虚拟类目部分需资质、严查版权。
- 写：没有给个人智能体的发布接口。

## 我们的经验
- 2026-07-12 CRM 调研：淘宝个人店可行但不如闲鱼轻，按 CEO 指示"先罗列不下钻"（OPC 内部记录，2026-07-12）。
- 2026-09：外贸业务合作方开着淘宝店代理多个品牌，待查其在卖的型号和价格作情报（OPC 内部记录，2026-09）。
- 只研究过。

## 已知阻力
- 进得去：登录墙加脚本渲染，机器人识别严。
- 看得懂：商品信息结构化，但页面壳要渲染。
- 办得成：开放平台要商家资质；个人店要身份证实名。
- 稳不稳：没测过。
- 能付钱：买方付款走支付宝，智能体无正规代付通道。
- 守规矩：条款禁自动化抓取；虚拟类目资质和版权查得严。
