# Gitee

## 一句话
国内的代码托管平台。OPC 多次决定"GitHub 主仓、Gitee 镜像"（国内 Agent 和小白用户走 Gitee），包括本仓；但到 2026-10-25 还没有真建过一个 Gitee 镜像。

## 智能体怎么进门
- Git 协议推拉；REST API v5 带私人令牌；仓库页面公开可读。
- 公开仓要经平台审核才能对外展示（国内平台惯例，本卡未在我们的文档里核到具体规则，待评时查）。

## 我们的经验
- 2026-07-12：获客链路 c 定"Gitee 镜像为主链接"——GitHub 大陆裸连困难，目标用户是小白，"拉仓库"这步会流失大半；抖音口播提"Gitee 搜 XX"可以，放链接不行（OPC 内部记录，2026-07-12）。
- 2026-10-17：政策知识库国内版规划"Gitee 加国内云"，海外版 GitHub（OPC 内部记录，2026-10-17）。
- 2026-10-25：智能体平台评估定 GitHub 主仓加 Gitee 镜像同步（OPC 内部记录，2026-10-25）。
- 调研时从一个受限网络环境直接搜 Gitee 三种方式都不可达：搜索页脚本渲染取不到、API 域名被环境策略拦、jina 代理 422（OPC 内部记录，2026-10-25）——这是环境问题，不能算 Gitee 的账，但说明它的搜索页不是机器可读的。
- 没有建过仓、没有推过代码。

## 已知阻力
- 进得去：国内可达是它的卖点；搜索页脚本渲染。
- 看得懂：API 有 swagger；网页搜索对爬虫不可见。
- 办得成：镜像同步要在我们自己的脚本里做（OPC 内部记录，2026-10-25），还没写。
- 稳不稳：没测过。
- 能付钱：免费档够用。
- 守规矩：公开仓审核规则待查。
