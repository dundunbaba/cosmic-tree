# 支付宝

## 一句话
国内两大收款通道之二。商户 API 完整但不对自然人开放；电脑网站支付常要求 ICP 备案，和海外托管有真实冲突。2026 年推出面向 AI 服务结算的「AI 收」，个人开发者限期 0 费率，是"智能体对智能体收费"值得盯的口。

## 智能体怎么进门
- 商户 API：要企业或个体户主体签约；电脑网站支付、当面付等产品有备案要求。
- 支付宝小程序：企业账号、营业执照、企业 ICP。
- 「AI 收」：面向 AI 服务的自动结算，个人开发者 0 费率到 2026-12-31（调研记录）。
- 个人收款码：央行 259 号文禁止远程经营收款；静态码付款侧单日 500 元。

## 我们的经验
- 2026-06-16：微信／支付宝都不向自然人开放支付 API；海外托管（Vercel 加 Cloudflare）与"支付宝电脑网站支付常要求已备案"是真实冲突点，阶段 0 用爱发电规避（OPC 内部记录，2026-06-16）。
- 2026-10-16：「AI 收」个人开发者 0 费率，但支付宝小程序本身要企业账号（OPC 内部记录，2026-10-16）。
- 2026-10-17 核验：个人收款码不能远程收；静态码日限 500 元（OPC 内部记录，2026-10-17）。
- 闲鱼确认收货的钱到支付宝（OPC 内部记录，2026-10-25）。
- 没接过任何支付宝接口。

## 已知阻力
- 进得去：文档公开；签约要主体和实名。
- 看得懂：开放文档结构化。
- 办得成：个人无路径；网站支付要备案。
- 稳不稳：没测过。
- 能付钱：智能体替人付款无正规通道；「AI 收」是收款侧的新口。
- 守规矩：央行 259／296 号文。
