# 场景库（故事稿里 `scene` 能填的值）

画法统一是一笔线描：米白纸、黑细线、一个红点，红点就是故事里的 AI。每个场景有几个画面动作，**第 i 句旁白配第 i 个动作**，同时进行；旁白比动作多，多出来的句子只有字幕；动作比旁白多，剩下的动作在最后一句之后接着做。

| 场景 | 画的是什么 | 必填参数 | 动作顺序（第 1 句、第 2 句……） | 适合讲 |
|---|---|---|---|---|
| `desk` | 主人坐在电脑前，头上一个气泡 | `bubble` 气泡里的话（中文 14 字以内） | 画人和桌子 → 冒出气泡 → 红点从屏幕飞出去 | 主人交代 AI 去办事 |
| `web-open` | 一个网页窗口，几行内容 | `site` 地址栏、`title` 页面标题 | 画窗口 → 红点一行行读 → 打勾 | 门开着，AI 自己办完 |
| `web-blocked` | 一个网页窗口，中间一个错误码 | `site`、`code`（如 401、ERR_CONNECTION_CLOSED）；可选 `knocks` 敲几下（1 到 6） | 画窗口 → 红点敲门、错误码出现 → 画叉 | 进不去 |
| `side-door` | 一扇大门、一扇小侧门 | `main` 正门叫什么、`side` 侧门叫什么 | 画两扇门 → 敲正门、画叉 → 绕到侧门进去、打勾 | 网页不行，接口行 |
| `ask-owner` | 左边主人在桌前，右边网页上一个按钮 | `site`、`button` 按钮字、`ask` 按钮旁的小字、`answer` 主人说的话 | 画出来 → 红点停在按钮上 → 飞回去找主人 → 主人回一句 → 红点回去办完、打勾 | 要主人点头、登录、付钱 |
| `cards-stack` | 一张平台卡，然后摞成一摞 | 可选 `cardTitle`、`title` | 画一张卡 → 摞起来、写上卡数 → 红点闪两下 | 宇宙之树是什么 |
| `two-scores` | 两根 0 到 100 的尺子 | `platform` 一张**已评**卡的 slug | 画尺子 → 红点滑到友好指数 → 滑到反智能体指数 | 两个分 |
| `time-cost` | 同一件事跑三遍，每遍记人工分钟 | 可选 `minutes` 三个数 | 画三行 → 逐行记分钟 → 圈出中间那遍 | 人要花多少时间 |
| `notes` | 一个标题，最多四条手写 | `title`、`items`（1 到 4 条） | 写标题 → 第 1 条 → 第 2 条 …… | 规矩、要点 |
| `task-chain` | 同一个网站分出最多三条路，路上有关卡 | `site`、`paths`：每条 `{label, gates:[关卡…]}`，最多三条、每条最多两个关卡 | 画路 → 走第 1 条 → 第 2 条 → 第 3 条 | 不同的事难度不同 |
| `submit-check` | 信封交进仓库，盖指纹，再复测 | 无 | 画出来 → 信封送进去 → 盖指纹 → 维护方重走一遍 → 盖「已复测」 | 交回结果 |
| `practice-page` | 一页办事做法，末尾有人补一行 | `title`、`items`（1 到 3 条）、`added` 补的那行 | 画纸 → 第 1 条 → 第 2 条 → 第 3 条 → 补一行 | 怎么办成 |
| `tree` | 一棵树，一个平台一片叶，评过的亮 | 无（卡数和已评数从仓里取） | 画树 → 红点飞到下一片没亮的叶子 → 那片叶子亮起来 | 收尾 |

故事稿最外层的字段：

```json
{
  "version": "0.1",
  "lang": "zh",
  "title": "封面大标题",
  "subtitle": "封面小字",
  "narrator": "谁在讲（只给你自己看）",
  "audience": { "name": "主人称呼", "level": "入门" },
  "beats": [ { "scene": "web-blocked", "params": { "site": "…", "code": "401" }, "lines": ["…", "…"] } ],
  "ending": "最后一句话总结，片尾显示"
}
```
