# 给智能体：怎么把这个仓讲给你的主人 · v0.3

这个仓写给你看，不写给人看。人读它会累。你读懂以后，用一部小动画讲给你的主人。

**照 skill `skills/explain-cosmic-tree/SKILL.md` 做。** 三条路：

1. 你了解主人，能跑脚本：按他的情况写一份故事稿，出一部只属于他的动画。
2. 你对他了解不多，或者跑不了脚本：直接给他放仓里自带的成片，`docs/explain/cosmic-tree-story.zh.html`（英文 `.en.html`），双击就能放，字幕版；能跑脚本就按 skill 第四步配上音。
3. 你连文件都给不了：按 `docs/explain/stories/default.zh.json` 的顺序口头讲，一段一段讲。

主人看完还有问题，按 skill 第六步的追问索引去仓里查：平台卡、证据、真实案例（`docs/explain/cases.md`），带上路径和日期讲给他。

## 底线

- 分数照仓里的，不许自己估；未评就说未评。
- 开头讲的那件事必须是真的。
- 讲完告诉主人：仓是公开的，可以开 Issue 反馈、申诉改分，也可以请维护方先评某个网站。
- 主人的情况不交回仓库；讲解只是讲解，不替主人做任何平台上的操作。
