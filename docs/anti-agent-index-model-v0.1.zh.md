# 反智能体指数模型 v0.1 · 2026-10-25

> 作者：OPC 维护团队（智能体辅助整理，经人核验）· 日期：2026-10-25

> **2026-10-25 CEO 定名**：官方叫"反智能体指数"，配对"友好指数"。下文"反 Agent 指数"一律读作"反智能体指数"。

> CEO 2026-10-25 要："反 Agent 指数也要给个模型"。和"Agent 友好度"配对用：友好度量的是平台**替 Agent 修了多少路**，反 Agent 指数量的是平台**主动设了多少拦**。一个平台可以两头都低（没修路也没设拦，荒地），也可以两头都高（给合作方开正门、把其他人拦在外面，围墙花园）。两个数一起看才公平。

## 一、定义与叫法

- **反智能体指数**（CEO 2026-10-25 定名）：平台针对自动化访问主动设置的阻拦强度，0 到 100，越高越反。英文 Anti-Agent Index。
- 只记"主动设拦"的证据，不把"没做"算进来（没做归友好度扣分）。
- 这是描述，不是道德评价：平台拦机器人常有正当理由（滥用、成本、隐私）。文稿里要写平台给的理由（如果它公开说过）。

## 二、六个方面与权重（满分 100，越高越反）

| 方面 | 权重 | 看什么 | 检查项（每项 0 / 1 / 2 分：0 没有、1 有但有限、2 全面） |
|---|---|---|---|
| 1 封门 | 25 | 把 Agent 挡在门外 | ① robots.txt 明确禁 AI 爬虫（GPTBot、ClaudeBot 等按名禁） ② 识别到 Agent 的 User-Agent 就拒绝或降级 ③ 封云服务商和数据中心 IP 段 ④ 没有 API，或曾有后来关掉、涨到小玩家用不起 ⑤ 公开内容也要登录甚至实名手机号才能读 |
| 2 识别与拦截 | 20 | 认出机器就拦 | ① 验证码出现频率（正常频率访问也弹） ② 浏览器指纹检测：无头或自动化浏览器被认出 ③ 挑战页（"请稍候，正在验证"）拦住首次访问 ④ 内容故意靠脚本二次加载、字段加密（如薪资加密显示）、DOM 混淆 |
| 3 惩罚 | 20 | 发现自动化之后怎么对待 | ① 封账号（含主账号连坐） ② 限流会升级：重试被加重惩罚 ③ 封 IP ④ 自动化发的内容被限流或隐藏 |
| 4 条款与法律 | 15 | 白纸黑字怎么说 | ① 条款禁止自动化访问或抓取 ② 对抓取方发过律师函或起诉（公开报道） ③ 把"AI 训练"或"Agent 使用"单列为禁止 |
| 5 经济壁垒 | 10 | 用钱拦 | ① API 定价对个人和小公司不可及 ② 只对机器人收费或要求数据授权协议 ③ 合作方才有正门，普通开发者没有 |
| 6 对抗升级 | 10 | 拦得多勤 | ① 近 12 个月针对机器人的改动次数（以公开工具的失效记录为证，如 Agent Reach 的更新日志） ② 改动是否专门针对已知工具 |

等级：0 到 19 开放，20 到 39 设防，40 到 59 戒备，60 到 79 敌对，80 到 100 封锁。

## 三、怎么测：只探测，不突破

反 Agent 指数的测法和友好度不同：**我们不绕过任何拦截**。探针只做平台对任何人都公开的事：

1. 读 robots.txt、条款页、开发者文档、定价页：封门、条款、经济三方面大半靠读。
2. 用标准 Agent 以诚实的 User-Agent、正常频率访问公开页三次，记是否被拒、被降级、弹验证码、见挑战页。遇验证码就停，记 2 分，不解、不换 IP、不换账号。
3. 对比一次普通浏览器访问同一页，看差别是不是专门针对机器（这是判定"识别"的依据）。
4. 惩罚方面只收集公开证据：平台公告、官方帮助页、开发者社区里的封号案例、公开工具的更新日志；我们不拿自己的账号去试封。
5. 对抗升级看公开工具（Agent Reach、yt-dlp 这类）的失效记录和平台改版公告，按时间数。
6. 每项带证据：截图、原文、链接、日期。没证据不算分。

这条规矩同时是我们自己的红线：评测过程不做任何突破验证码、伪装身份、换 IP 的事，否则评价体系自己先违规。

## 四、和友好度放一起：四格图

| | 反 Agent 指数低 | 反 Agent 指数高 |
|---|---|---|
| **友好度高** | 开放场：修了路也不设拦 | 围墙花园：给合作方开正门，其他人拦在外面 |
| **友好度低** | 荒地：没修路，也没设拦，Agent 能进但难走 | 堡垒：不修路还设拦 |

每个平台两个数一张卡，视频里说"X 平台：友好度 62，反 Agent 指数 71，围墙花园"。排行榜做两张：最友好榜、最反 Agent 榜，后一张更容易传播，但每一分都要有证据（见下）。

## 五、数据文件

和友好度同一份平台卡，加一段：

```json
"anti_agent": {
  "score": 71, "grade": "敌对",
  "aspects": {
    "block": {"weight": 25, "score": 18, "checks": [{"id": "1.1", "score": 2, "evidence": "robots.txt 2026-10-25 快照：Disallow GPTBot、ClaudeBot"}]},
    "detect": {}, "punish": {}, "terms": {}, "cost": {}, "escalate": {}
  },
  "platform_statement": "平台公开说明的理由（如有）"
}
```

## 六、底线

- 每个分都有公开证据，被评方有异议按证据改，改分留痕。国内评企业说错算商业诋毁，这一条比友好度更要紧，因为这张榜是在说人家"反"。
- 不收被评平台的钱；不替平台做"降低反 Agent 指数"的付费整改，这和评价冲突。平台想改进，给的是公开的方法，不是私下的服务。
- 测法不突破任何拦截。
